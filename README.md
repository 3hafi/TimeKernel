# Trajectory (local-first MVP)

Trajectory combines calendar (`.ics`) + emoji micro-logs to produce quantified behavior analysis, trajectory forecasts, and what-if planning.

## Why this is different
Instead of only describing behavior, Trajectory estimates near-future outcomes and tradeoffs (sleep, focus windows, stress/load proxies), then suggests high-payoff experiments from your own data.

## Install
```bash
go mod tidy
go build -o trajectory ./cmd/trajectory
```

## Complete setup instructions

### 1) Initialize local config + storage
```bash
./trajectory config init
```

Trajectory stores data locally in:
- `~/.trajectory/config.json`
- `~/.trajectory/trajectory.db`

### 2) Export Google Calendar to ICS
From Google Calendar web UI:
1. Open **Settings**.
2. Under **Settings for my calendars**, select your calendar.
3. Open **Integrate calendar**.
4. Use the iCal link (or export) and save as a local file, e.g. `google.ics`.

Then import:
```bash
./trajectory import-ics ./google.ics
```

### 3) Add emoji micro-logs
Fast manual log:
```bash
./trajectory log "📱 doomscroll 30m"
./trajectory log "😴"
./trajectory log "🌅"
```

Manual timestamp:
```bash
./trajectory log -t "2026-01-01 23:30" "😴"
```

Bulk import text or CSV:
```bash
./trajectory import-logs ./logs.txt
./trajectory import-logs ./logs.csv
```

Text log format:
```text
YYYY-MM-DD HH:MM <tokens...> [optional note]
```
Example:
```text
2026-01-01 22:30 😴 📱 doomscroll 20m [late wind-down]
```

CSV log format:
```csv
timestamp,tokens,notes
2026-01-01 22:30,😴,sleep start
2026-01-02 07:00,🌅,wake
```

### 4) Generate outputs
Report:
```bash
./trajectory report --from 2026-01-01 --to 2026-01-07 --format md --out report.md
```

Trajectory forecast:
```bash
./trajectory trajectory --days 14 --out trajectory.md
```

What-if simulation:
```bash
./trajectory whatif --date 2026-01-08 --alloc "study=2h,gaming=1h,doomscroll=30m,exercise=45m" --out whatif.md
```

Data quality helper:
```bash
./trajectory doctor
```

## 3-minute quickstart
```bash
./trajectory config init
./trajectory import-ics ./sample.ics
./trajectory import-logs ./logs.txt
./trajectory log "📱 doomscroll 30m"
./trajectory report --from 2026-01-01 --to 2026-01-07 --format md --out report.md
./trajectory trajectory --days 14 --out trajectory.md
./trajectory whatif --date 2026-01-08 --alloc "study=2h,gaming=1h,doomscroll=30m,exercise=45m" --out whatif.md
./trajectory doctor
```

## CLI command spec
- `trajectory config init`
- `trajectory import-ics <file.ics>`
- `trajectory import-logs <file.txt|file.csv>`
- `trajectory log "<tokens>"`
- `trajectory log -t "YYYY-MM-DD HH:MM" "<tokens>"`
- `trajectory report --from YYYY-MM-DD --to YYYY-MM-DD --format md|html --out report.md`
- `trajectory trajectory --days 7|14 --out trajectory.md`
- `trajectory whatif --date YYYY-MM-DD --alloc "study=2h,gaming=1h,doomscroll=30m,exercise=45m" --out whatif.md`
- `trajectory doctor`

## SQLite schema
- `events`: ICS events with idempotent `external_id` unique key.
- `logs`: timestamped micro-logs with idempotent `unique_key`.
- `imports`: import source hashes for dedupe tracking.

## Config template (`~/.trajectory/config.json`)
Generated by `config init`, includes:
- `day_boundary_hour`
- `workday_start`, `workday_end`
- `token_categories` and `token_weights`
- `calendar_keyword_categories`
- `privacy_redact_titles`

See full template at `examples/config.template.json`.

## Design decisions
- Local-first SQLite, no network calls.
- Deterministic rules + lightweight statistics for explainability.
- Conservative defaults with confidence labels when sample sizes are low.

## Limitations
- ICS parser handles common VEVENT fields but not full RFC edge cases.
- Coefficients are rule-based in sparse-data scenarios.
- HTML output is minimal wrapper around markdown in MVP.
